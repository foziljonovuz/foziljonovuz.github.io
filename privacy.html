Privacy Policy

Last updated: October 30, 2026

YouTube AI Agent ("the app") is a private tool used only by its owner, Bakhrom Foziljonov, for his own YouTube channels. No other people sign in to the app.

What data the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API and the YouTube Analytics API to upload videos, set thumbnails, manage playlists, update video details and read statistics for the owner's own channels.

How data is stored

All data stays on the owner's own computer: OAuth tokens, the IDs and scheduled times of uploaded videos, and simple channel statistics. Nothing is sold, shared with third parties or used for advertising. Statistics are refreshed and overwritten regularly.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at Google Account permissions. Stored tokens are then deleted from the owner's computer.
